# Unkernel

Researched: 2026-11-28

**Category:** wasm-os

**What it does:** Unkernel compiles the real Linux kernel to WebAssembly, allowing Linux system calls to run inside a WASM sandbox in browsers or edge runtimes. It lets developers run unmodified Linux binaries as WASM modules.
