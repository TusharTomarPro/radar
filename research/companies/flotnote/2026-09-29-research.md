# Flotnote

Researched: 2026-09-29

**Category:** note-taking

**What it does:** Flotnote is a macOS app that lets users create floating Markdown notes that stay on top of other windows. Users can write, format, and organize notes without leaving their current workflow.

**Likely revenue model:** A one‑time purchase/license fee for the desktop app, with no recurring subscription.

**India equivalent already exists:** Zoho Notebook

**India fit note (AI first pass, verify yourself):** The product assumes a sizable Mac user base and a habit of using persistent desktop notes, which is less common in India where Windows and mobile devices dominate. However, the core need for quick note capture exists, so a similar app could succeed if adapted for cross‑platform use.
